# 모바일 앱 기획서

## 1. 앱 이름
오늘 하루 (Flutter 모바일 앱)

음성 기록을 바탕으로 하루를 돌아보는 모바일 애플리케이션이다. 사용자의 일과 패턴에 맞춘 유연한 보관 주기와 기록 정책을 제공한다.

## 2. 사용자 (누가 쓰나)
- 일기를 손으로 직접 쓸 시간이 없거나 귀찮은 사람
- 늦은 밤이나 새벽까지 활동하여 자정이 지난 시간도 '어제의 하루'로 기록하고 싶은 사람
- 목소리로 하루의 순간을 가볍게 메모하고 보관하고 싶은 사람

## 3. 해결할 문제 (왜 필요한가)
- 하루 일과를 손으로 일일이 작성하는 부담을 줄인다.
- 00:00 자정을 기준으로 날짜가 끊겨 야간 활동 기록이 분절되는 문제를 해결한다.
- 불필요한 음성 파일로 기기 용량이 낭비되는 것을 방지하면서도, 필요한 음성은 사용자가 소장할 수 있도록 한다.

## 4. 기능 목록 (핵심 기능 및 개선 사항)
- **음성 녹음 및 재생:** 당일 음성을 간편하게 녹음하고 앱 내에서 다시 듣기
- **오디오 파일 보관 기간 설정:** 1일 ~ 14일 범위 내에서 사용자가 보관 기간을 설정 (초과 파일 자동 삭제)
- **오디오 파일 다운로드/내보내기:** 원하는 음성 파일을 기기 외부 저장소나 파일 앱으로 내보내 영구 소장
- **하루 전환 기준 시각 설정:** 밤 9시(21:00) ~ 익일 아침 9시(09:00) 사이에서 사용자가 하루가 넘어가는 시각을 지정 (논리적 날짜 적용)
- **오늘의 일기 자동 생성 및 편집:** 보관된 오디오를 바탕으로 텍스트 일기 초안 생성
- **일기 수정 권한 제한:** 일기가 생성된 논리적 당일에만 수정 가능 (전환 시각이 지난 과거 일기는 읽기 전용으로 보호)
- **캘린더 탐색:** 날짜별 저장된 일기 조회 및 일기가 있는 날에 달력 마커(점) 표시

## 5. 화면 구성
- **녹음 탭:**
  - 상단: 논리적 오늘 날짜 라벨 및 설정 버튼
  - 중앙: 녹음 카드 (상태 텍스트, 실시간 파형 애니메이션, 타이머, 녹음 시작/중지 버튼)
  - 하단: 오늘의 보관함 목록 (오디오 재생 컨트롤러, 파일 다운로드/내보내기 버튼)
  - 액션: [오늘의 일기 만들기] 플로팅/고정 버튼
- **일기 작성/수정 화면 (모달 또는 페이지):**
  - 제목 및 본문 텍스트 에디터 (과거 일기인 경우 읽기 전용 카드)
  - 저장 버튼
- **캘린더 탭:**
  - 월 이동 컨트롤 및 달력 그리드 (일기 작성일 표시)
  - 선택한 날짜의 일기 상세 카드 (제목, 날짜, 본문)
- **설정 모달/화면:**
  - 하루 전환 시각 선택 (21:00 ~ 익일 09:00)
  - 오디오 보관 기간 슬라이더/피커 (1일 ~ 14일)

## 6. 사용 흐름 (사용자가 하는 행동 순서)
1. 필요할 때마다 [녹음 시작]을 눌러 목소리로 일과를 남기고 [녹음 중지]를 누른다.
2. 보관함에서 원하는 음성을 다시 듣거나, 보관하고 싶은 파일은 [다운로드]를 눌러 기기에 저장한다.
3. 하루를 마칠 때 [오늘의 일기 만들기]를 누른다.
4. 생성된 일기 초안을 확인하고 필요 시 내용을 수정한 뒤 [저장]을 누른다.
5. 당일 안에는 언제든 다시 일기를 수정할 수 있으나, 설정한 하루 전환 시각이 지나면 일기는 읽기 전용으로 잠긴다.
6. 캘린더 탭으로 이동해 이전 날짜를 선택하면 과거의 일기를 확인할 수 있다.

## 7. 만들지 않을 것
회원가입 · 로그인 · 중앙 서버 동기화 · 다른 사람과의 공유 (모든 데이터는 온디바이스 로컬 저장)

## 8. 완료 기준
- 마이크 권한 요청 후 안정적으로 오디오 녹음 및 재생이 가능하다.
- 오디오는 사용자가 지정한 보관 기간(1~14일) 동안 유지되며, 기간이 지난 파일은 자동 삭제된다.
- 특정 오디오 파일을 로컬 저장소로 다운로드/내보내기 할 수 있다.
- 설정한 하루 전환 시각(21:00~09:00)에 맞춰 녹음과 일기의 귀속 날짜가 정확히 계산된다.
- 당일 생성된 일기는 수정 및 저장이 가능하고, 전환 시각이 지난 과거 일기는 수정할 수 없다.
- 캘린더에서 날짜별로 저장된 일기를 열람할 수 있다.
