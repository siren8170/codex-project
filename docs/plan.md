# 임시 웹 버전 기획서

## 1. 웹 버전 이름
오늘 하루

모바일 앱을 사용할 수 있는 환경이 마련될 때까지 브라우저에서 실행하는 임시 웹 버전으로 개발한다. `index.html`을 직접 열며 서버와 빌드 도구를 사용하지 않는다.

## 2. 사용자 (누가 쓰나)
- 일기 쓸 시간이 없거나 부족한 사람
- 직접 일기를 필기하며 작성하기 귀찮은 사람

## 3. 해결할 문제 (왜 필요한가)
- 손으로 일기를 작성할 시간이 없거나 아깝다고 느끼는 경우가 있기 때문

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)
- 녹음하기
- 당일 오디오 내용을 요약하여 텍스트 일기로 작성하기
- 작성된 일기를 캘린더에서 확인할 수 있음
- 캘린더에서 날짜를 클릭하면 일기를 확인할 수 있음
- 당일 오디오는 브라우저 내부 저장소에 보관하고, 날짜가 바뀌면 삭제하기

## 5. 화면 구성 (위에서 아래 순서)
- 캘린더 전환 버튼
- 녹음 버튼 / 중지 버튼
- 오늘의 일기(오디오 종합 일기 작성) 버튼
---
- 캘린더
- 각 일차 버튼

## 6. 사용 흐름 (사용자가 하는 행동 순서)
1. 녹음 버튼을 클릭한다
2. 중지 버튼을 클릭한다
3. 오늘의 일기를 클릭한다
4. 일기가 화면에 나오며 수정이 가능하다
5. 저장 버튼을 누르면 저장된다
6. 저장된 일기는 캘린더 전환 버튼을 누르면 캘린더 페이지에서 확인할 수 있다

## 7. 만들지 않을 것
회원가입 · 로그인 · 서버 · 다른 사람과 공유

## 8. 완료 기준
- 녹음 가능
- 녹음을 중지하면 당일 오디오가 브라우저 내부 저장소에 보관됨
- 오늘의 일기를 생성하고 수정·저장할 수 있음
- 캘린더에서 날짜를 선택하면 저장된 일기를 볼 수 있음
- 날짜가 바뀌면 지난날 오디오가 삭제되고 저장된 일기는 남음
