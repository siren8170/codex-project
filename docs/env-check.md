# 웹 버전 실습 환경 확인 목록

- [ ] 편집기에서 ‘오늘 하루’ 웹 버전 작업 폴더(Windows `C:\codex-work\test`)를 열었다. 확인 방법: 파일 탐색기에 `AGENTS.md`와 `docs` 폴더가 보이는지 본다.
- [ ] Codex 확장에 실습 계정으로 로그인했다. 확인 방법: VS Code의 Codex 확장을 열어 로그인한 계정을 확인한다.
- [ ] 작업 폴더 맨 위에 `AGENTS.md`가 있다. 확인 방법: VS Code 탐색기에서 작업 폴더 바로 아래에 파일이 보이는지 확인한다.
- [ ] 새 대화에서 Codex가 `AGENTS.md` 규칙을 요약했다. 확인 방법: 새 대화를 열어 규칙 요약을 요청하고 답변을 확인한다.
- [ ] 규칙에 어긋나는 요청(라이브러리 설치)을 Codex가 거절하거나 되물었다. 확인 방법: 새 대화에서 라이브러리 설치를 요청하고 Codex의 응답을 확인한다.
- [ ] Codex가 파일을 만들거나 명령을 실행하기 전에 허락을 묻는다. 확인 방법: 파일 생성이나 명령 실행을 요청하고 실행 전에 허락을 묻는지 확인한다.
- [ ] `docs/plan.md`와 `docs/prompt-design.md`가 있다. 확인 방법: VS Code 탐색기의 `docs` 폴더에서 두 파일을 찾는다.
- [ ] `git --version`이 동작한다. 확인 방법: 터미널에서 `git --version`을 실행해 버전이 표시되는지 본다.
- [ ] 브라우저(Windows: Chrome 또는 Edge / macOS: Chrome 또는 Safari)가 열린다. 확인 방법: 해당 브라우저를 실행해 창이 열리는지 본다.
- [ ] 웹 파일을 만든 뒤 `index.html`을 브라우저에서 직접 열 수 있다. 확인 방법: 파일을 열어 ‘오늘 하루’ 화면이 표시되는지 본다.
- [ ] 브라우저에서 마이크 접근을 허용할 수 있다. 확인 방법: 녹음 버튼을 눌러 권한 요청이 표시되고 허용 후 녹음이 시작되는지 본다.
- [ ] 코드와 문서에 개인정보·비밀번호·API 키가 없다. 확인 방법: 코드와 문서를 살펴보고 개인정보, 비밀번호, API 키가 포함되지 않았는지 확인한다.
