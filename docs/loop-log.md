# 반복 기록 (모바일 앱)

`AGENTS.md`의 반복 규칙에 따라, 사람이 에뮬레이터/실기기에서 검증한 결과와 수정 이력을 기록한다.

## 2일차 — Mock 기반 정적 UI 검증

- 시작 조건: `flutter run`으로 Android 에뮬레이터에서 앱이 실행된다
- 완료 기준: 콘솔 예외 없음 / ① 녹음·캘린더 탭 전환 / ② 설정에서 전환 시각·보관 기간 변경 시 즉시 반영 / ③ 과거 일기 읽기 전용 / ④ 스크롤 끝 오버스크롤 효과 없음
- 종료 조건: 완료 기준을 모두 통과하거나, 같은 실패가 3회 반복되면 멈춘다

| 회차 | 실패한 기준 | 실패 근거(한 일 → 보인 것) | 보낸 피드백 요약 | 바뀐 파일 | 재검증 결과 |
|---|---|---|---|---|---|
| 처음 점검 | 실행 불가 | `flutter run` → C: 디스크 공간 부족으로 에뮬레이터 시작 실패 | 공간 확보 후 재시도 | - | 11:47 ①②③ 통과, 예외 로그 없음 |
| 1회 | ④ | 녹음·캘린더 탭 스크롤 끝에서 당김 → 오버스크롤 효과 표시 | 오버스크롤 효과 제거 (원문 미기록, 파일 수정 시각·캡처로 추정) | `lib/presentation/screens/main_screen.dart` | 통과 (`docs/screenshots/*-overscroll.png`, `*-scroll-end.png`) |
| 2회 | | | | | |
| 3회 | | | | | |

- 종료 이유: 모두 통과
- 남은 문제: 실제 녹음·권한·파일 저장·내보내기·일기 DB 미구현(다음 단계)
- 다음에 지시를 바꾼다면: 에뮬레이터 실행에 필요한 디스크 여유 공간을 시작 조건에 포함한다.

## 3일차 — 도메인 레이어 적용 후 일기 당일 수정 검증

- 시작 조건: 도메인 레이어(`LogicalDateService`, `DiaryPolicy`, `AudioRetentionPolicy`) 적용 후 `flutter test` 통과
- 완료 기준: 캘린더 탭에서 오늘 일기를 [수정] → 내용 변경 → [저장] 하면 예외 없이 카드에 반영된다
- 종료 조건: 완료 기준을 통과하거나, 같은 실패가 3회 반복되면 멈춘다

|---|---|---|---|---|---|
| 1회 | 일기 당일 수정 | 오늘 일기 [수정] → 내용 변경 → [저장] → 빨간 오류 화면(`'_dependents.isEmpty': is not true`) | 저장 시 반영되어야 함, 날짜 조회 로직은 건드리지 말 것 | `lib/presentation/screens/calendar_tab.dart`, `test/presentation/diary_edit_test.dart` | 통과: 위젯 테스트 녹색, 에뮬레이터에서 제목 수정 반영·예외 로그 없음 (`docs/screenshots/calendar-edit-saved.png`) |
