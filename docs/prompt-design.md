# 프롬프트 설계서

## 1. 목표
녹음 기능을 이용하여 하루 일과를 정리하고 일기를 쓰는 임시 웹 버전을 만드려고 합니다. 모바일 앱을 사용할 수 있는 환경이 마련될 때까지 브라우저에서 실행합니다.

## 2. 맥락
- 녹음 버튼을 이용해 당일 오디오 파일을 브라우저 내부 저장소에 보관합니다. 그 뒤 오늘의 일기 버튼을 눌러 당일 오디오를 바탕으로 텍스트 일기를 작성합니다.
- 텍스트 일기는 사용자가 수정하고 저장할 수 있습니다.
- 저장된 일기는 캘린더에서 날짜를 선택해 다시 볼 수 있습니다.
- 저는 HTML·CSS·JavaScript 기초를 배우고 Dart를 조금 공부해본 학생입니다.

## 3. 제약
- 예시 데이터는 "점심을 먹은 일"처럼 가상의 내용만 씁니다.
- HTML·CSS·JavaScript로 개발하고, 빌드 도구·서버·프레임워크 없이 `index.html`을 브라우저에서 직접 열어 실행합니다.
- 브라우저의 마이크 접근 권한을 요청하고, 녹음 파일과 일기는 해당 브라우저의 내부 저장소에 보관합니다.
- 모바일 앱 전용 기능이나 Android/iOS 앱 설치를 전제로 하지 않습니다.
- 오디오를 분석해 일기로 변환해야 하며, 서버 없이 브라우저에서 실행할 수 있는 구체적인 방식을 구현 시 제안합니다. 브라우저 지원 범위와 제한도 설명합니다.

## 4. 출력 형식
- 만들 파일 목록과 파일마다 역할을 한 줄씩 적어 주세요.
- 화면에 보일 요소를 위에서 아래 순서로 적어 주세요.
- 마지막에 완료 기준을 하나씩 어떻게 확인할지 적어 주세요.

## 5. 완료 기준
1. 녹음을 할 수 있다.
2. 그날 녹음된 오디오 파일을 브라우저 내부 저장소에 보관한다.
3. 당일 녹음된 오디오 파일을 사용해 텍스트 일기를 제공할 수 있다.
4. 캘린더 형태의 페이지에서 특정 날짜를 누르면 그날의 일기를 볼 수 있다.
5. 메인 화면에 녹음 버튼, 캘린더 이동 버튼, 오늘의 일기 버튼이 있다.
6. 날짜가 바뀌면 지난날의 오디오 파일이 삭제되고 저장된 일기는 남는다.
